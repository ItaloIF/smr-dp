# Model Card

## Model Summary

The bundled checkpoint performs heatmap localization on displacement-frequency
matrices generated from strong-motion acceleration records.

```text
Architecture: DeepLabV3+
Encoder: EfficientNet-B3
Input: 1 x 256 x 1024 displacement-frequency matrix
Output: 1 x 256 x 1024 probability heatmap
Checkpoint: models/HP_DeepLabV3Plus/best_model.pt
```

## Intended Use

The model is intended for research on automated strong-motion record processing,
especially joint P-wave arrival identification and high-pass corner-frequency
selection.

Suitable uses:

- reproducing the repository demo,
- testing the published workflow on comparable strong-motion records,
- comparing alternative architectures or processing settings,
- generating candidate picks for expert review.

Unsuitable uses:

- operational earthquake response without independent validation,
- records outside the training domain without quality control,
- final engineering decisions without expert review and uncertainty assessment.

## Inputs and Outputs

Inputs are displacement-frequency matrices generated by `src/dataset.py`. Each
row corresponds to one candidate `fcHP`; columns are normalized time samples.

Outputs are probability heatmaps. The helper in `src/metrics.py` smooths the
heatmap and extracts the maximum coordinate. Downstream code converts that
coordinate to `tP` and `fcHP`.

## Limitations

- Performance depends on matching the preprocessing pipeline used during
  training.
- Very noisy records, clipped records, and records with unusual sampling rates
  should be inspected carefully.
- The included checkpoint is a research artifact. Treat predictions as candidate
  values rather than authoritative labels.
